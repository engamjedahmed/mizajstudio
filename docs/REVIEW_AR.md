# مراجعة نسخة بوابة الوضوح — Mizaj Studio

## ما هذه النسخة؟

نسخة تطوير محلية تعيد بناء اتجاه الكحلي والكريمي والذهبي من صور 03.0C وD-2.
هذه ليست ملفات D-2 الأصلية؛ لم نعثر على مصدرها الكامل. لم تُستبدل النسخة
المنشورة على Mizajj.com ولم يُرفع هذا الفرع إلى GitHub.

## ما الذي يتضمنه التنفيذ؟

- صفحة عربية وإنجليزية بالخدمات الخمس ومعلومات التواصل الموجودة في المشروع.
- مجسم Three.js من خمس وحدات وأربع وصلات، مع تسلسل اختياري مدته 4.8 ثانية.
- أزرار تشغيل وإيقاف واستئناف وإعادة وعرض صورة ثابتة، وبدائل لتقليل الحركة
  وفشل WebGL. يحتاج سلوكها الفعلي إلى فحص متصفح.
- كتالوج توضيحي للبحث والتصفية والاختيار ونسخ ملخص الاختيار.
- حاسبة احتياج بمدخلات قابلة للتغيير، وبيانات وأمثلة تعليمية واضحة.
- صور WebP وخطوط محلية، وتهيئة بناء مناسبة لـVercel.

## فتح حزمة المراجعة

افتح الملف `MIZAJ_Clarity_Gateway_Review.html` بعد تنزيله على جهازك.
جميع الخطوط والصور والكود مضمّنة فيه. قد يعرض تطبيق الملفات على الهاتف
معاينة ثابتة فقط؛ جرب فتحه في متصفح يدعم JavaScript وWebGL.

هذه نسخة مستقلة للمراجعة، لذا تُضمّن مكتبة Three.js كاملة. النسخة المخصصة
للاستضافة تبقيها في ملف منفصل لا يُحمَّل حتى طلب التشغيل. لا تستخدم حجم
الملف المستقل للحكم على سرعة الموقع المنشور مستقبلًا.

تحتوي الحزمة أيضًا على `source` للمصدر و`production-build` للبناء العادي.
للمعاينة البرمجية، يستطيع Codex تشغيل `npm ci` ثم `npm run dev` داخل
مجلد المصدر. ويمكن لمن لديه Python تشغيل البناء من مجلد الحزمة:

```sh
python -m http.server 8018 --bind 127.0.0.1 --directory production-build
```

ثم يفتح `http://127.0.0.1:8018/` على الجهاز نفسه.

## ما تحقق وما بقي؟

نجح البناء وفحص الصياغة والحسابات وحدود بعض المدخلات ومراجعة مفاتيح
الترجمة والمراسي. فُحصت الصورتان الناتجتان من Blender بصريًا. لم ينجح
الوصول إلى الصفحة داخل المتصفح السحابي؛ لذلك بقي تقرير `design-qa.md`
بحالة **blocked**. لم يُقَس FPS أو Core Web Vitals أو أداء هاتف فعلي.

اللقطة المرفقة للمجسم صورة تصيير فعلية من الهندسة المعاد بناؤها، وليست
لقطة من الموقع الحي ولا دليلًا على تطابق إضاءة Blender مع WebGL.

## الخطوة التي تحتاج موافقة صريحة

رفضت المراجعة الآلية الدفع إلى مستودع GitHub العام لأن نشر محتوى النسخة
الجديدة يحتاج موافقتك الصريحة. المطلوب هو اعتماد رفع فرع المراجعة
`feat/cinematic-clarity-reconstruction` إلى المستودع العام وإنشاء معاينة
Vercel محمية، مع إبقاء `main` وMizajj.com الحالي دون تغيير.

بعد ذلك نفحص الصفحة الحية والتفاعل والموبايل، ثم يكون اعتماد استبدال
الموقع الرسمي خطوة منفصلة مبنية على النسخة التي رأيتها.
